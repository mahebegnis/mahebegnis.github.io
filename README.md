# mahebegnis.github.io

Page de présentation et CV

- `index.html` : page unique
- `assets/css/site.css`, `assets/js/site.js` : styles et animations
- `assets/vendor/` : GSAP 3.15.0, ScrollTrigger et Lenis 1.3.26, hébergés ici (versions, empreintes et licences dans `VENDOR.md`)
- `fonts/` : Instrument Serif et Instrument Sans, auto-hébergées (SIL OFL 1.1)
- `CV_Mahe_Begnis.pdf` : CV, 2 pages
- `qr/` : QR code pointant vers cette page

Aucun cookie, aucune mesure d'audience, aucune ressource chargée depuis un autre site.
Politique de sécurité du contenu : seuls les scripts et styles du site sont autorisés.
La page reste complète sans JavaScript et en mode « moins d'animations ».
